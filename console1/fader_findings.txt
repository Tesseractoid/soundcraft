Console 1 Fader mk1 - what it sends with NO Softube software running (probes on the Mac Studio, 2026-11-20)
MIDI port: "Console 1 Fader" (in + out). Same SysEx framing as the Console 1 (c1sysex.py).

PLAIN-MIDI MODE (power-up state; THE MOTORS MOVE in this mode)
  Fader n position: CC 100 + 2*(n-1), channel 1, 0..127 (7-bit only; no LSB seen). Fader 1 = CC 100, fader 10 = CC 118.
  Motors: send the same CC back to the Fader -> it moves (confirmed fader 1).
  Touch fader n: CC 11 - n (fader 1 = CC 10, fader 2 = CC 9, fader 3 = CC 8), 127 touched / 0 released.
  Buttons: plain CCs (map being confirmed by Fader Probe 3).

DIRECT MODE (after SysEx cmd 0x20 data 7F, repeated every 0.5 s; Fader answers cmd 0x21 data 7F)
  Fader n position: cmd 0x18 data [2*(n-1), lsb, flag|msb], value = ((msb & 0x3F) << 7) | lsb = 0..1023; 0x40 flag = touched.
  Touch fader n: cmd 0x00 data [20 - 2*(n-1), 7F/00]  (fader 1 = 0x14, fader 10 = 0x02)
  Select n = 0x7A - 6*(n-1); Mute n = Select n + 2; Solo n = Select n + 4  (cmd 0x00, 7F press / 00 release)
  Layer 0x1C, Assign/favourites 0x1A, Page left 0x42, Page right 0x40, Shift 0x16
  Knob: cmd 0x18 data [0x14, dir, 01]  (FaderBridge notes: 7F = clockwise)
  Motors: NOT moved by mirroring cmd 0x18 (with or without flag), cmd 0x19 or cmd 0x08. Unknown how, so not usable yet.

UPDATE (probes 5 and 6, 2026-11-20 evening) - THE WORKING COMBINATION
  Put the Fader in direct mode (cmd 0x20 7F every 0.5 s) for 1024-step reading, touch and the full button map,
  AND move the motors with plain CC 100 + 2*(n-1) (7-bit). Both work at the same time; reading stays 1024 steps.
  Motor accuracy measured by touch-readback: lands on the 128-step grid, ~4-6 counts (of 1024) below target.
  A touch makes the Fader report its true position (cmd 0x18, 0x40 flag set) - handy for checking.
  CC 101 or CC 68 as an LSB: no finer placement.
  cmd 0x02 [00,msb,lsb], cmd 0x08 [00,lsb,msb] and cmd 0x08 [lsb,msb] sent fader 1 to the BOTTOM whatever the target
  (a lead for a real 1024-step motor message with a different layout - not explored yet). cmd 0x03: no effect.

LIGHTS (probes 7, 8 and the light check, 2026-11-20 late) - CONFIRMED on the hardware
  Plain CC 127 = on, 0 = off; works in plain AND direct mode.
  Select fader n = CC 81 - 5*(n-1); Mute = Select + 1; Solo = Select + 3   (fader 1: 81/82/84, fader 10: 36/37/39)
  Layer = CC 14, Page - (left) = CC 34, Page + (right) = CC 33, CC 32 = "display" light.
  Pan dots: CC 96 value moves a dot, but only across the first 3 dots - rest of the ring not mapped yet.
  The button INPUT CCs (plain mode) are different: Select n = 61 - 3*(n-1), Mute +1, Solo +2; Layer 14, Assign 13,
  Page left 33, Page right 32, Shift 11.
  If the lights stop answering after experiments, unplug the Fader for 5 s.
